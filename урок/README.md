## 🧠 Теория

### Что такое LiDAR



<img width="864" height="492" alt="RPLIDAR_A_01" src="https://github.com/user-attachments/assets/84516a32-528b-46bc-ab3c-d576987f39a7" />


**LiDAR** (Light Detection and Ranging) — сенсор, измеряющий расстояние до объектов с помощью лазера.

**Принцип:**

```
Лазерный луч → объект → отражение → приёмник → расстояние
```

**Формула:**

```
Расстояние = (скорость света × время) / 2
```

> Деление на 2 — потому что луч проходит путь туда и обратно.

---

### RPLIDAR A1

| Параметр | Значение |
|----------|----------|
| Дальность | 0.15 – 12 м |
| Частота измерений | 8000 Гц |
| Скорость сканирования | 5.5 Гц |
| Угловое разрешение | ≤ 1° |
| Диапазон | 360° |
| Интерфейс | UART @ 115200 bps |
| Питание | 5V, 100 мА |
| Точность | 1% (до 3 м) |
| Принцип | Лазерная триангуляция |

**Что это значит:**

- Лидар вращается 5.5 раз в секунду
- За один оборот делает 360° снимок
- Каждое измерение — расстояние до объекта

---

### Что такое SLAM

**SLAM** = Simultaneous Localization And Mapping

**Проблема курицы и яйца:**

```
Чтобы построить карту → нужно знать, где ты
Чтобы знать, где ты → нужна карта
```

**Решение:** делать это одновременно.

**Зачем нужен:**

| Где | Что делает |
|-----|------------|
| Робот-пылесос | Карта комнаты |
| Беспилотная машина | Понимание дороги |
| Дрон | Навигация в помещении |

---

### Три типа SLAM

| Тип | Примеры | Особенность |
|-----|---------|-------------|
| **Фильтр SLAM** | EKF, UKF, Particle | Одна догадка о положении |
| **Граф SLAM** | Cartographer, ORB-SLAM | Помнит все положения |
| **Scan Matching** | **Hector SLAM** | Сравнивает сканы с картой |

> Сегодня разберём **Scan Matching** — Hector SLAM.

---

### Hector SLAM

**Что это:** алгоритм, строящий карту через сравнение текущего скана с уже построенной картой.

**Ключевые особенности:**

| Особенность | Значение |
|-------------|----------|
| Нужна одометрия? | ❌ Нет |
| Метод | Scan matching (Gauss-Newton) |
| Работает с | RPLIDAR, ручное сканирование, дроны |
| Публикует | `/map`, `/tf`, `/slam_out_pose` |

**Цикл работы:**

```
1. Взять скан из /scan
2. Сравнить с картой
3. Найти совпадение (Gauss-Newton)
4. Обновить карту
5. Повторить
```

**Схема:**

```
/scan → Сравнить → Совпадение → Обновить → /map
```

---

### TF

**TF** — библиотека, связывающая системы координат.

**Команда:**

```bash
rosrun tf static_transform_publisher 0 0 0 0 0 0 map laser 100
```

**Что означает:**

| Параметр | Значение |
|----------|----------|
| `0 0 0` | Позиция (x, y, z) |
| `0 0 0` | Поворот (yaw, pitch, roll) |
| `map` | Родительская система |
| `laser` | Дочерняя система |
| `100` | Обновление каждые 100 мс |

**Почему без TF не работает:**

```
Без TF:
Лидар: "Стена в 2 м!"
RViz: "2 м от ЧЕГО?" ❌

С TF:
Лидар: "Стена в 2 м от laser!"
TF: "laser в точке (0,0) карты"
RViz: "Стена в (2,0)!" ✅
```

## 🖥️ Практика

### Подготовка

```bash
# Разрешение на USB (один раз за загрузку)
sudo chmod 666 /dev/ttyUSB0

# Source ROS
source /opt/ros/noetic/setup.bash
```

---

### Запуск

#### Терминал 1: ROS Master

```bash
roscore
```

> **Что сказать:** "Это мастер ROS. Без него узлы не общаются."

---

#### Терминал 2: Драйвер лидара

```bash
rosrun rplidar_ros rplidarNode
```

> **Что сказать:** "Драйвер подключился к лидару и публикует данные в `/scan`."

---

#### Терминал 3: Проверка данных

```bash
rostopic echo /scan -n 1
```

> **Что сказать:** "Это интерфейс ROS. Топик `/scan` содержит расстояния и углы."

**Что увидеть:**

```yaml
angle_min: -3.14
angle_max: 3.14
angle_increment: 0.0174
ranges: [1.2, 1.5, 2.0, ...]
frame_id: "laser"
```

---

#### Терминал 4: Визуализация сканов

```bash
rviz
```

**В RViz:**

1. Fixed Frame → `laser`
2. Add → By topic → `/scan` → LaserScan
3. OK

> **Что сказать:** "Красные точки — это лазерные сканы."

---

#### Терминал 5: TF

```bash
rosrun tf static_transform_publisher 0 0 0 0 0 0 map laser 100
```

> **Что сказать:** "TF связывает системы координат."

---

#### Терминал 6: Hector SLAM

```bash
rosrun hector_mapping hector_mapping
```

> **Что сказать:** "Hector SLAM подписывается на `/scan` и публикует карту в `/map`."

---

#### Терминал 7: Визуализация карты

**В RViz (уже открыт):**

1. Fixed Frame → `map`
2. Add → By topic → `/map` → Map
3. OK

> **Что сказать:** "Смотрите — карта появляется!"

---

### Демонстрация

**Что сделать:**

1. Медленно двигать лидар вперёд
2. Показать, как карта обновляется
3. Остановить — карта замирает

> **Что сказать:** "Карта обновляется только при движении."

---

### Сохранение карты

```bash
rosrun map_server map_saver -f my_map
```

**Что создаётся:**

| Файл | Что содержит |
|------|--------------|
| `my_map.pgm` | Картинка карты |
| `my_map.yaml` | Настройки |

> **Что сказать:** "Карта сохраняется как картинка."

## ⚠️ Проблемы и решения

| Проблема | Решение |
|----------|---------|
| `Permission denied` на `/dev/ttyUSB0` | `sudo chmod 666 /dev/ttyUSB0` |
| Карта не появляется | Fixed Frame = `map` |
| Карта не обновляется | Двигать лидар медленнее |
| TF не работает | Проверить, что команда запущена |
| `/scan` пустой | Проверить подключение USB |
